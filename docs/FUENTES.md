## Acceso a las fuentes oficiales desde el entorno de desarrollo

Los portales oficiales (crtm.es, datos.madrid.es, ign.es, renfe.com, metromadrid.es) no eran accesibles desde el entorno donde se generó el proyecto. Se usaron copias íntegras de los mismos ficheros GTFS (Mobility Database) y datos de Overture Maps (S3 público). `scripts/fetch_data.sh` intenta siempre primero la URL oficial.
